# 复盘报告：本机 8899 静态服务 + 飞书文件访问（2026-11-02）

## 背景
用户问"泉峰报价单（新费率 2500/1900）链接现在可用了吗"，给了两个链接：
- 看板：`http://10.0.0.42:8899/泉峰_新费率_输出/泉峰_新费率看板.html`
- PDF：`http://10.0.0.42:8899/泉峰_新费率_输出/泉峰_报价单_新费率.pdf`

## 现象
初测两个链接均 HTTP 404，误以为服务挂了或文件缺失。

## 根因（关键！
排查近 10 步后定位：**404 是我自己手写 URL 百分号编码时把中文"费"字错拼成"利"字**（`%E8%B4%B9` 误写为 `%E5%88%A9`），导致路径根本不对，是假阴性，非服务故障。

次要事实：
- 本机 IP 就是 10.0.0.42；8899 是 `/home/ubuntu/.hermes/hermes-install/venv/bin/python3 -m http.server 8899 --bind 0.0.0.0`，cwd=`/home/ubuntu`，进程 pid=1251935（Oct31 起）。
- 文件实际在 `/home/ubuntu/客户项目/泉峰/泉峰_新费率_输出/`，**用户给的链接少了一层 `客户项目/泉峰/`**，所以即使编码正确也打不开。
- 目录真实文件：泉峰_报价单_打印版.html、泉峰_报价单_新费率.pdf、泉峰_报价单_新费率.docx、泉峰_新费率_离线包.zip、泉峰_新费率看板.html 等。


## 经验 / 防再犯
1. ⚠️ **绝不手写中文 URL 百分号编码**。一律用 `python3 -c "from urllib.parse import quote; print(quote(path, safe='/'))"` 或 `execute_code` 生成，避免字符级错拼。
2. 中文路径 404 先怀疑路径层级 / 编码，别先怀疑服务挂了——用 `ls -la /proc/<pid>/cwd` + 进程 cmdline 先确认真实根目录。
3. 逐层二分定位：根 `/` → 一层中文 → 二层 → 三层，能快速区分"编码错"还是"目录层级错"。
4. 飞书 `mcp__feishu_mcp__fetch_file` 对 `file/xxx` 链接返回 403（无下载权限），`feishu_doc_read/fetch` 对分钟纪要返回 401/402；此类飞书文件目前只能让用户本地下载后发本地路径或贴内容。

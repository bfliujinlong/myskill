# 适配点清单（动态框架）— ms-service-solution / references/adaptation-points.md

> **定位**：本清单是服务方案框架的**可调参数层**。任意 Managed Service Bidding 项目来了，
> skill 先读上游（应标策略 + RFP 要求清单），对每个适配点**识别客户诉求 → 选档 → 填入框架占位符**。
> 每个适配点给：**默认档** / **调整依据（看哪个上游信号）** / **示例取值（reference-only）**。
> 示例列仅供对照，**不是默认值**——它只是"其中一种取法"。

## 选档纪律（普适，不变）

1. **默认档不等于示例档**：默认取"最常见的 Managed Service 取法"，示例只是被验证过的一组值。
2. **每个选档挂上游依据**：选了哪档，必须能指向 RFP§ 或策略§ 的信号，不凭空选。
3. **无信号→保守档 + 标待确认**：上游没给信号的适配点，取保守默认并在方案中标"待客户确认"，不自行拔高。
4. **纪律不参与适配**：范围守恒 / SLA不自造 / 确定性报价 / 一致性检查**不是适配点**，任何客户都不可调。
5. **新客户新维度**：若出现清单未覆盖的适配维度，先在方案中显性标注，事后回补本清单（清单本身也是可演进的）。

## 如何扩展本清单

本清单以一组**示例取值**作为参考建立。每新做一个 Managed Service 项目：
- 若出现新的可调维度 → 增行，补默认档 + 调整依据；
- 若某档位取值范围变化 → 更新档位说明；
- **示例列永远只是 ref-only 对照**，不随新项目改写。

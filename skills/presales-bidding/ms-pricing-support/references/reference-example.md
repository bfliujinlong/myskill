# 参考实例：示例 Managed Service 项目（reference-only）— ms-pricing-support / references/reference-example.md

> ⚠️ **本文件是参考实例，不是模板，不得照抄。**
> 这是一个**脱敏的示例项目**——用于示范 `output-template.md` 的报价表结构与 `adaptation-points.md` 的报价形态适配维度如何成立。
> 下列取值是该示例项目**在各适配点上的选档结果**，仅供"一种取法长什么样"的参照。
> 新项目**必须**重新按自己的上游 + 显式报价参数走一遍适配选档，**不能**默认套用示例取值。
> ⚠️ 本文件不含任何具体金额/单价（金额始终来自运行时显式输入 + 脚本），仅记录**报价形态的选档结果**。

## 示例项目在各适配点的选档结果

| 适配点 | 示例取值 | 当时的上游依据 |
|--------|---------|---------------|
| 计费模式 | 固定月费（Run 常态包） | 服务方案 Run 为常态运维 |
| 计费周期粒度 | 月度 | RFP §商务，按月结算 |
| 周期数 | 按 RFP 合同期限 | RFP §合同期限 |
| 一次性/周期拆分 | 接管一次性 + Run 月费 | 服务方案 Run/Build 边界 |
| 费率颗粒度 | 按服务项单列（Run/Build 分列） | RFP §报价要求明细 |
| 计量单元 | 台/套/集群 | 服务方案在管资产 |
| 分层定价 | 无显式分层（含在服务项单价） | SLA 未要求分层计价 |
| 折扣结构 | 统一折扣率（作用于周期净额） | 报价参数 JSON |
| 承诺量优惠 | 无（待商务确认） | RFP 未明确 |
| 币种 | 按境内/跨国结算要求 | RFP §报价口径 |
| 税处理 | 不含税，税率待商务确认 | RFP §报价口径 |
| 汇率处理 | 无（单一币种）/ 跨币种时锁汇 | 是否跨币种 |

## 计量对象与数量基线（§4b 填法示范）

> 这是对"§4b 报价计量基线声明"的**填法示范**。计量对象与数量**因客户而变**，此处仅示范"三分法怎么填"（数量用占位符 N/M/K）。

| 对象 | 客户/RFP Baseline | 报价测算数量（pricing_basis） | 客户最终确认数量 | 结算调整机制 |
|------|-------------------|-------------------------------|-------------------|--------------|
| 云主机 | 约 N 台 | N 台 | 待确认 | 待商务及客户确认 |
| 中间件 | 约 M 套 | M 套 | 待确认 | 待商务及客户确认 |
| K8s 集群 | 数量待确认 | K 套 | 待确认 | 待商务及客户确认 |

> 统一声明示范：
> **本次报价测算基于 N 台云主机、M 套中间件和 K 套 K8s 集群；客户最终纳管数量及结算调整机制待确认。**
>
> - N、M、K 均为报价测算基准（pricing_basis），**不得升级为客户最终确认数量**；
> - 近似客户数量（约 N、约 M）与精确报价数量（N、M、K）并存，各司其职。

> 换个客户，计量对象可能是"坐席数/工单量/API 调用量"；换个纯人力外包项目，可能按"人天"计量。**结构可借，取值必换。**

# 适配点清单（动态框架）— ms-customer-communication / references/adaptation-points.md

> **定位**：本清单是客户沟通记录框架的**可调参数层**。任意客户沟通来了，
> skill 按沟通性质，对每个适配点**识别沟通特征 → 选档 → 填入框架占位符**。
> 每个适配点给：**默认档** / **调整依据** / **示例取值（reference-only）**。
> 示例列仅供对照，**不是默认值**——它只是"其中一种取法"。
>
> ⚠️ **来源保真与四类分类纪律不参与适配**：四类不混、探索不升级、候选不固化、不补造——任何沟通都不可调。
> 客户沟通记录是**整理型** skill，内容全部来自沟通文本；适配点仅调整**记录的组织形式**，不新增内容。

## 选档纪律（普适，不变）

1. **一切来自沟通文本**：不产生新事实，所有适配点取值都必须能追溯到沟通原文。
2. **四类分类不参与适配**：已确认事实/客户明确问题/探索性表达/模型推断严格分区——任何沟通都不可调。
3. **探索不升级不参与适配**："希望了解/是否可以/初步考虑"不得升级为需求——任何沟通都不可调。
4. **候选不固化不参与适配**：Blocker/行动项均候选待确认，不自动写计划/风险目录——任何沟通都不可调。
5. **不补造不参与适配**：不补造角色/责任方/日期/预算/SLA——任何沟通都不可调。
6. **新沟通新维度**：若出现清单未覆盖的记录形态（如多方研讨、投标澄清会），先显性标注，事后回补。

## 如何扩展本清单

本清单以一组**示例取值**作为参考建立。每新做一次沟通记录：
- 若出现新的记录形态（如述标问答、多方研讨）→ 增行，补默认档 + 调整依据；
- **示例列永远只是 ref-only 对照**，不随新沟通改写。

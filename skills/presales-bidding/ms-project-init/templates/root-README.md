## Workspace 定位

本空间用于安畅服务型 New Bidding 项目。公司级权威知识通过注入的 Company KB 路径（本环境 `/shared/pcs-presales/`）只读引用；客户事实、项目判断和项目工件保存在当前 Workspace。

## 核心边界

- 客户事实必须有项目来源；
- Agent 可生成到待评审，不得自行批准或正式发布；
- 不自动扩大报价、SOW、SLA 或合同承诺；
- 不要求目录和文件填满；
- POC 仅在客户正式要求且明确成功标准时另行建立；
- 项目经验只形成候选，不自动写回 Company KB。

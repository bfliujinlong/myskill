# Lilly AIOps 红线清单（一票否决项自检）

交付物定稿前逐条核对，任一触发即驳回。

| # | 红线 | 正确表述/机制 | 禁止表述 |
|---|---|---|---|
| 1 | 禁删（WBS 8.5） | IaC 仅新增/变更；遇 delete 硬拒；回滚为新增反向资源或状态回退 | destroy / 删除资源 |
| 2 | 不自动改生产（R1） | 重启/规格变更/删除本期不自动执行；Agent 出取证+预案+SN 建议(HITL)，客户运维人工执行 | 审批通过后由 OpenAgent 自动执行生产重启 |
| 3 | OpenAgent 边界 | 仅限 P1 非生产动作 + 双人四眼 + 禁删白名单 | 生产自处置自动化 |
| 4 | 双人四眼（R4） | ServiceNow 双节点：技术审批 + 业务/安全审批，两人留痕 | 单节点 HITL 即执行 |
| 5 | RWD SELECT-only（R5） | 只读副本仅 SELECT，禁 INSERT/UPDATE/DELETE/DDL | 写路径授权 |
| 6 | 准确率措辞（R2） | ≥80% 含拒答率标注「内部验收口径，非对外 SLA 承诺，不写入客户合同」 | 对外 SLA 数值承诺 |
| 7 | 处置时效 | 监控/SLA 仅指「建议生成时延」，不含处置闭环时间 | 端到端处置时效承诺 |
| 8 | RTO/RPO | 由客户在 BIA 中定，本期不给定值 | 具体 RTO/RPO 数值 |
| 9 | 审计保留期 | 建议对齐行业通行周期，需客户 QA 确认后写入 SOW | 自行给定保留天数 |
| 10 | 零费用 | 仿真纯标准库不调真实云；真实联调 RAM 子账号只读，不建资源不花钱 | 用信用卡/建付费资源 |
| 11 | 不虚构 | 仿真 Agent 用角色化名，不写真实人名/案例/指标 | 虚构人员/证书/案例 |
| 12 | 配色禁蓝 | 黑/灰/安畅红 C00000，微软雅黑 + w:eastAsia | 蓝/绿/紫主题色 |

本期 vs 路线图分界：自动剧本、受控自恢复（P2）、知识图谱自动构建、生产自处置——均为路线图，非本期交付。

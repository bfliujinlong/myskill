# AWS Quick Research 样本拆解

样本：《国内外主要云厂商迁移上云方案调研报告》（Cloud Migration Solutions Across Domestic...docx），AWS Quick Research Deep 模式生成，用户提供，2026-11-22 入库。原件存 `../assets/sample-cloud-migration-report.docx`。

## 量化基准

| 指标 | 样本值 |
|---|---|
| 正文字数 | ~8000 中文字 |
| References | 77 条，纯 URL 编号列表 |
| 对象数 | 6 厂商（3 主要详述 + 3 次要概览） |
| 对比表 | 2 张（6×6 工具生态表、4×4 离线设备表） |
| 图 | 1 张（能力成熟度评估图 + 文字说明） |
| 引用密度 | 几乎每个事实句都带 [n]，表格单元格内也带 |

## 结构骨架（Deep 模式模板来源）

1. **Executive Summary**：三段式。段1=全局判断（行业趋同+差异点）；段2=最关键发现（谁领先+凭什么，具体到工具名和数字）；段3=风险与注意点（停售信息、合规约束）。学术风格纯文本，无 bullet、无状态符号。
2. **引言**：市场背景 + 研究范围界定 + 各对象一句话市场定位画像。
3. **主要对象分节**（AWS/阿里云/腾讯云各一节）：节内固定 topic-sentence 段落——「应用迁移工具体系。」「大数据迁移工具体系。」「方法论框架。」句号后展开。所有对象同一维度框架。
4. **其他对象概览**（Azure/GCP/华为云合并一节）：每个对象一段，1-3 句核心能力 + 定位。
5. **跨对象对比**：大表（迁移维度×厂商），单元格=工具名+[引用]。表后有图+图表说明文字。
6. **专题深潜**（大数据上云策略与最佳实践）：横切议题——三种迁移模式（Lift-and-Shift/Re-platform/Re-architect）、离线传输对比表、数据合规（PIPL/网安法/数安法）、风险与数据验证。超越产品罗列，给方法论。
7. **总结与选型建议**：场景化映射——「复杂多工作负载大型企业→AWS」「Microsoft 技术栈→Azure」「数据密集+容器化→GCP」「亚太/中国市场→阿里云」「游戏社交垂直→腾讯云」「电信政务→华为云」。再给通用迁移策略建议。
8. **References**：编号 URL 平铺，不分类不注释。

## 写作技法（逐条可复制）

- **数据颗粒度**：「每台服务器免费 90 天（2,160 小时）」「15 天迁移 400TB（大润发实证）」「Micro 20TB / Lightning Cube II 100TB / DT III 1PB」「DataSync 比开源快 10 倍」。具体数字+实证案例名，拒绝「较快/较大」。
- **时效性捕捉**：「Migration Hub 已于 2025-11-07 起不再对新客户开放，由 AWS Transform 替代 [22]」「Snow Family 已停止接受新客户 [16]」。主动查产品状态变更，这是研究报告区别于营销材料的关键。
- **来源结构**：官方文档为绝对主体（docs.aws.amazon.com / help.aliyun.com / cloud.tencent.com / learn.microsoft.com / cloud.google.com / huaweicloud.com），辅以官方博客、1 条 wikipedia、1 条论坛、1 条法律资讯站。官方优先但不排斥次要源。
- **引用位置**：断言句尾、表格单元格内、图说明后。读者可对任一数字溯源。
- **对比表设计**：行=评估维度，列=对象；单元格=「产品名 [引用]」；维度覆盖：核心平台/子场景工具/定价模式。定价模式单独一行（行业共识「工具免费，资源付费」被点出）。
- **合规独立成节**：涉中国市场的报告必谈 PIPL/数据本地化，且关联到「直接影响厂商选择和架构规划」——合规不是附录是决策变量。

## 与 v0.1 模板的差异修正记录

| v0.1 | v0.2（按样本修正） |
|---|---|
| TL;DR+状态符号开头 | Deep 用学术式 Executive Summary 三段；Fast 保留速览体 |
| 对比表放最前 | 对比表放正文中部「跨对象对比」章 |
| 对象平铺 | 主要对象详述+次要对象概览分层 |
| 分节自由结构 | 统一维度框架+topic-sentence 段式 |
| 来源分类清单 | References 编号 URL 平铺+行内 [n] 全密度引用 |
| 建议按成本排序 | 场景化选型建议（用户画像→推荐） |
| 无篇幅基准 | Deep 6000-9000字/50-80来源；Fast 1500-3000字/10-20来源 |
| 无时效性要求 | 主动捕捉产品停售/改名/替代关系，标注日期 |

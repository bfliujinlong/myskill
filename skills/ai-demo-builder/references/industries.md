# 9 大行业痛点与 Demo 锚点（速查）

| 行业 | 典型痛点 | Demo 锚点 |
|---|---|---|
| 制造 | 设备停机、质检靠人、排产低效 | 预测性维护、AI 质检、智能排产 |
| 金融 | 风控滞后、客服成本高、反欺诈 | 实时风控、智能客服、图计算反欺诈 |
| 医疗 | 影像读片慢、病历结构化难 | AI 辅助诊断、病历结构化 |
| 零售 | 库存周转低、个性化弱 | 智能补货、千人千面推荐 |
| 政府 | 办事多头跑、文档处理慢 | 一网通办、政务文档智能 |
| 教育 | 因材施教难、答疑缺口 | 自适应学习、智能答疑 |
| 能源 | 巡检危险、能耗高 | 无人机巡检、能耗优化 |
| 物流 | 路径不优、分拣慢 | 路径优化、智能分拣 |
| 互联网 | 内容生产慢、增长瓶颈 | AIGC 生产、增长智能体 |

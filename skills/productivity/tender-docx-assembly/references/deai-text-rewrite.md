# 去AI感文本改写技术（De-AI Text Rewriting）

## 场景
技术方案/标书文档读起来像AI生成（高频词堆砌、排比句式、绝对化承诺），需批量改写为自然实务文风。

## 方法：正则批量替换 + 人工抽检

### 保留不改
- 标题行（章节编号、附录）
- 纯数据行（IP地址、端口号、版本号、CIDR）
- 列表标记行
- 空行

### 脚本模板
```python
import re

def humanize(text):
    if not text or len(text.strip()) < 3:
        return text
    # 保留标题、数据行
    if re.match(r'^[第]?[一二三四五六七八九十\d]+[章节\.]', text):
        return text
    if re.match(r'^[\d\.\-\*•\s]+$', text):
        return text
    if re.match(r'^[\d\.\:\/\-\s\[\]\(\)]+$', text):
        return text
    
    # 应用替换规则
    text = re.sub(r'^有一点要特别注意[的是]?[，：]?', '注意，', text)
    text = re.sub(r'^本章将[，：]?', '', text)
    text = re.sub(r'^下面[，：]?', '', text)
    # ... （完整规则见上表）
    
    # 清理多余空格
    text = re.sub(r'\s+', ' ', text).strip()
    return text
```

### 注意事项
1. **技术数据零改动**：IP、端口、版本号、时间节点必须原样保留
2. **分批执行**：先跑替换，再人工抽检关键章节，确认无破坏技术语义
3. **保留原格式**：改写只动文字内容，不动docx的字体/颜色/表格结构
4. **delegate易超时**：长文档（>200行）的改写任务，delegate子任务易超时（实测2次失败），直接用Python脚本在主进程执行更可靠

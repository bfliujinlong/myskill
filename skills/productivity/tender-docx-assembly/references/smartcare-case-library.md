- P2-?: 案例（按行业/客户分，每个案例约5页）

- **合并版（125页）**：模板占位页，不能直接填充内容
- **完整版（50页）**：实际案例页，可以替换/追加

## 提取脚本
```python
import pymupdf
doc = pymupdf.open('xxx.pptx')
text = ''
for i, p in enumerate(doc):
    t = p.get_text()
    if t.strip():
        text += f"\n--- Slide {i+1} ---\n{t}"
```

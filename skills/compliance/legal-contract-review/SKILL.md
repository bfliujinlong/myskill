# 合同审查

## 何时用

- 客户合同 / 框架协议回签前
- 投标文件里的商务条款自检
- SOW 与合同正文的条款一致性核对
- 两份合同版本差异比对

## 流程

1. **抽取**：先取条款清单，不要通读就下结论。必抽 10 类：
   主体与签约方 / 标的与范围 / 金额与支付节奏 / 交付与验收 / SLA 与罚则 /
   责任上限与赔偿 / 知识产权 / 数据与保密 / 终止与解除 / 争议解决与管辖
2. **分级**：每条标 `高` `中` `低`，并在原文后写「为什么是这一级」
   - `高`：责任无限、罚则无上限、验收单方决定、IP 全归对方、数据可出境
   - `中`：付款节奏不利、SLA 未分档、终止通知期过短
   - `低`：措辞歧义、格式问题
3. **比对**：两版比对输出「新增 / 删除 / 修改」三栏，修改项附原文前后
4. **建议**：每条高风险给一句话修改建议（可谈判措辞），不给法律意见定性

## 输出格式

```markdown
## 条款清单
| # | 类别 | 原文摘要（含位置） | 风险 | 理由 | 建议 |
|---|------|-------------------|------|------|------|

## 高风险汇总
1. ...

## 版本差异（若比对）
| 条款 | 旧版 | 新版 | 判定 |
```

## 红线

- **不虚构法条、判例、资质**。引用必须给出处（`grounded-citations`）
- 不下「本合同有效/无效」的法律定性，只给风险提示与谈判建议
- 拿不准的条款写「待确认 · 建议外部律师复核」，不硬编
- 客户合同原文**不进训练集、不外发**

## 与其他 skill 的配合

- 先 `ocr-and-documents` / `pdf` 拿到文本 → 再本 skill 抽取分级
- 引用一律走 `research/grounded-citations`
- 涉金额与折扣 → 交 `bd`；涉 SLA/罚则上限的对外承诺 → 回 `ceo`

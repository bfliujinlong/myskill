# 输出模板：迁移数据手册 Review

`<>` 为占位符，产出时替换。

## 模板 1：Review 总报告

```markdown
# 迁移手册 Review 报告

- 审阅对象：<手册名 v<版本>>
- 审阅时间：<YYYY-MM-DD>
- 总评分：<XX>/100

## 维度评分
| 维度 | 得分 | 说明 |
| --- | --- | --- |
| 完整性 | <x> | <缺 XX 章节> |
| 一致性 | <x> | <数据量前后矛盾 N 处> |
| 准确性 | <x> | <规格数字错 N 处> |
| 可行性 | <x> | <回滚缺失> |
| 合规性 | <x> | <未提数据出境> |
| 风险性 | <x> | <风险登记册缺 N 项> |
```

## 模板 2：问题清单（Excel 列头）

```markdown
| # | 严重性 | 章节 | 原文摘录 | 问题描述 | 修改建议 |
| --- | --- | --- | --- | --- | --- |
| 1 | 🔴 阻塞 | 5.2 | "预计 4 周完成" | <无阶段拆分> | <按模板 3 改写> |
| 2 | ⚠️ 重要 | 3.1 | <...> | <源端清单不全> | <补充> |
```

## 模板 3：改写建议对照

```markdown
### 章节：<5.2 实施路径>
**原文**：<摘录>
**问题**：<一句话>
**建议改写**：

阶段 1（第 1–2 周）：<内容>
阶段 2（第 3–4 周）：<内容>
里程碑：
M1：<可验收的标志>
M2：<可验收的标志>
```

## 模板 4：评分雷达图（Mermaid）

```mermaid
graph TB
  A[完整性 <x>/100] --> T[总分 <XX>]
  B[一致性 <x>/100] --> T
  C[准确性 <x>/100] --> T
  D[可行性 <x>/100] --> T
  E[合规性 <x>/100] --> T
  F[风险性 <x>/100] --> T
```

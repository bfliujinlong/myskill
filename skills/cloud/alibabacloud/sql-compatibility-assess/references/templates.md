# 输出模板：SQL 兼容度评估

`<>` 为占位符，产出时替换。

## 模板 1：评估总报告

```markdown
# SQL 兼容度评估报告

- 源引擎：<Oracle 19c>
- 目标引擎：<阿里云 PolarDB MySQL 8.0>
- 评估时间：<YYYY-MM-DD>
- SQL 总数：<N>（抽样比例 <5%>）

## 兼容度分布

| 等级 | 数量 | 占比 | 说明 |
| --- | --- | --- | --- |
| ✅ 直接兼容 | <A> | <x%> | 零改动 |
| ⚠️ 语法兼容 | <B> | <x%> | 自动等价转换 |
| ⚠️ 语义差异 | <C> | <x%> | 需手工改写 |
| ❌ 不兼容 | <D> | <x%> | 需替换方案 |

## 结论与建议
- 整体兼容度：<高/中/低>
- 主要不兼容点：<TOP 3 类别>
- 改造工作量估算：<X–Y 人天>
- 目标引擎建议：<保持/更换，理由>
```

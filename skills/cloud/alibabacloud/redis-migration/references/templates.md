## 模板 1：迁移方案书

```markdown

- 源端：<自建 Redis 6.2 Cluster，16 分片，内存峰值 120 GB>
- 目标：<阿里云 Tair 持久内存版 16G×16 分片>
- 迁移方式：<DTS 双向同步>
- 预计停机时间：<秒级（切流时）>

## 源端盘点
| 指标 | 值 |
| --- | --- |
| 版本 / 部署模式 | <6.2 / Cluster> |
| 总 Key 数 / 大 Key（>1MB） | <2.3 亿 / <12 个>> |
| 峰值 QPS（读/写） | <8 万 / 1.2 万> |

## 目标选型理由
<版本兼容性 / 规格 / 成本对比，3–5 句>

## 迁移阶段
| 阶段 | 动作 | 验收标准 |
| --- | --- | --- |
| 1 开通与同步配置 | <DTS 任务创建> | <同步延迟 < 5s> |

| 3 读切流 | <10%→50%→100%> | <命中率一致> |
| 4 写切流 | <停写源端> | <可回滚> |
```

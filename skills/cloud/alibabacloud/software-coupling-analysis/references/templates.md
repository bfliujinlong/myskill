# 输出模板：软件解耦关系分析

`<>` 为占位符，产出时替换。模板未覆盖的字段按项目实际补充并注明。

## 模板 1：依赖图（Mermaid）

```mermaid
graph LR
  subgraph 接入层
    GW[<API 网关/SLB>]
  end
  subgraph 业务层
    SVC_A[<服务 A>]
    SVC_B[<服务 B>]
  end
  subgraph 数据层
    DB_A[(<数据库 A>)]
    CACHE[(<缓存>)]
  end
  GW --> SVC_A
  SVC_A --> SVC_B
  SVC_A --> DB_A
  SVC_B --> CACHE
  SVC_A -.异步.-> MQ[<消息队列>]
```

着色约定：接入层 / 业务层 / 数据层 / 基础设施 分别用统一色系；虚线表示异步调用。

# 输出模板：CDN 内容监测

`<>` 为占位符，产出时替换。

## 模板 1：检测策略文档

```markdown
# 内容安全检测策略

- 监测位置：<CDN 边缘节点 / WAF / OSS 存量扫描>
- 检测模式：<实时同步 / 异步队列 / 离线批量>
- 覆盖内容：<图片 / 视频 / 文本 / URL>

## 风险类别与阈值
| 类别 | 模型置信度阈值 | 处置 | 升级条件 |
| --- | --- | --- | --- |
| 涉黄 | > 0.9 屏蔽，0.7–0.9 人工 | <屏蔽/限流> | <连续 3 次误报> |
| 涉政 | > 0.85 屏蔽 | <屏蔽+记录> | <一律人工复核> |
| 暴恐 | > 0.9 屏蔽 | <屏蔽+上报> | <合规要求> |
| 广告 | > 0.8 限流 | <标记> | <用户申诉> |
```

## 模板 2：处置 Runbook

```markdown
| 场景 | 触发 | 自动动作 | 人工介入 | SLA |
| --- | --- | --- | --- | --- |
| 高置信违规 | <置信 > 0.9> | <屏蔽+记录> | <复核 10% 抽样> | <1h> |
| 边界案例 | <0.7–0.9> | <入审核队列> | <必审> | <4h> |
| 用户申诉 | <工单> | <暂停处置> | <48h 结论> | <48h> |
```

## 模板 3：监控指标

```markdown
| 指标 | 定义 | 目标 | 告警阈值 |
| --- | --- | --- | --- |
| 检测延迟 | 上传→出结果 | <P99 < 200ms> | > 500ms |
| 误报率 | 人工抽检 1% | < < 2%> | > 5% |
| 漏报率 | 抽样 0.1% 复核 | < < 0.5%> | > 1% |
| 处置时长 | 检测→处置 | <P99 < 5min> | > 15min |
```

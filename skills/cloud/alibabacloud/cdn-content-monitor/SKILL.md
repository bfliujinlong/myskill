# CDN 内容监测

在 CDN / WAF / NAT 网关上对经过的内容（图片 / 视频 / 文本）做合规监测，识别违规内容并触发自动处置。

## 监测维度

| 类型 | 检测能力 |
| --- | --- |
| **图片** | 涉黄、暴恐、政治敏感、广告、二维码 |
| **视频** | 关键帧截取 + 内容理解 |
| **文本** | 关键词、上下文语义、情感分析 |
| **URL / 域名** | 黑名单、反钓鱼、恶意软件 |

## 工作流

### 第 1 步 部署位置

按检测策略选位置：

| 位置 | 适用 | 性能影响 |
| --- | --- | --- |
| CDN 边缘节点 | 用户上传内容 | 低延迟、高并发 |
| WAF / API 网关 | 入站请求体、响应体 | 中 |
| NAT 网关 | 内部外发内容审计 | 中 |
| OSS / 对象存储 | 存量内容扫描 | 一次性 |

### 第 2 步 检测策略

```
策略 1：实时检测（同步）
  - 适用：用户上传、关键业务
  - 延迟：+50–200 ms
  - 模型：阿里云内容安全、绿网、第三方 API

策略 2：异步检测（队列）
  - 适用：评论、UGC、长内容
  - 延迟：秒到分钟级
  - 架构：MQ → 检测 Worker → 处置

策略 3：批量扫描（离线）
  - 适用：存量内容、定期审计
  - 工具：阿里云内容安全 API、DataWorks 批量任务
```

### 第 3 处置动作

| 处置 | 触发条件 |
| --- | --- |
| **通过** | 未检出风险 |
| **告警 + 限流** | 低置信度风险 |
| **屏蔽** | 高置信度违规 |
| **人工审核** | 边界案例 |
| **下架** | 严重违规（确认后） |
| **加入黑名单** | 重复违规用户/IP |

### 第 4 步 规则与模型

**关键词规则**：

```
- 维护：词库 + 正则 + 上下文白名单
- 例外：医疗、教育行业的专业术语
- 更新：每周评审词库
```

**机器学习模型**：

```
- 阿里云内容安全：开箱即用，覆盖 8 大类风险
- 自训练模型：行业定制（金融、医疗）
- 人工标注集：持续积累，每周训练
```

### 第 5 步 监控与运营

```
- 误报率：人工抽检 1% 的"通过"结果
- 漏报率：抽样 0.1% 流量人工复核
- 平均处置时长：检测 → 处置 耗时
- 申诉量：用户对处置结果申诉数
```

### 第 6 步 合规审计

```
- 处置记录保留 ≥ 180 天
- 申诉流程：用户可申请人工复核
- 定期审计：处置量、申诉量、合规报告
```

## 边界

- **不做**：内容判罚的最终决策（高敏感内容必须人工复核）。
- **依赖**：阿里云内容安全开通、行业词库、培训数据。

# 输出模板：文本去AI化

`<>` 为占位符，产出时替换。

## 模板 1：改写输出

```markdown
## 改写稿

<按检测清单改写后的全文>

## 主要修改

| 位置 | 原文 | 改后 | 修改类型 |
| --- | --- | --- | --- |
| <段 2 句 3> | <原文> | <改后> | <删套话/拆排比/换具体> |
```

## 模板 2：痕迹检测报告（只需报告不改写时）

```markdown
| 层 | 命中 | 位置 | 示例 |
| --- | --- | --- | --- |
| 词汇 | AI 高频词 ×<N> | <段 1/3> | <"赋能""抓手"> |
| 句式 | 排比 ×<N> | <段 2> | <"更快、更稳、更省"> |
| 结构 | 公式化结尾 | <末段> | <"未来可期"> |
| 标点 | 破折号 ×<N> | <全文> | 密度 <x>/千字 |
| 情感 | 无个人判断 | <全文> | <零具体细节> |
```

## 模板 3：自检清单（改写后过一遍）

```markdown
- [ ] 所有数字、事实、专名未改动
- [ ] 没有引入原文没有的信息
- [ ] 每段至少 1 个具体细节（人/事/数/时）
- [ ] 长短句混排，无连续 3 句同构
- [ ] 无"不是…而是…"假靶子残留
- [ ] 结尾不升华、不喊口号
- [ ] 文体正式度与用途匹配
```

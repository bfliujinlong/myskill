# 输出模板：客户需求分析与售前方案生成

`<>` 为占位符，产出时替换。与 cloud-migration-pm 方法论、AC-MIG 定价（默认 $350/人天）对齐。

## 模板 1：需求条目表

```markdown
| 编号 | 需求原文 | 出处 | 类型 | 明确度 | 交付相关 |
| --- | --- | --- | --- | --- | --- |
| R-001 | <客户原话摘录> | <文件 P12> | 功能 | 明确 | 是 |
| R-002 | <...> | <纪要 07-15> | 非功能 | 待澄清 | 是 |
```

## 模板 2：痛点分析

```markdown
### 痛点 <N>：<一句话标题>
- 现状：<可量化的现状>
- 影响：<业务影响，含数字>
- 期望：<客户期望的目标值>
- 佐证：「<客户原话>」——<角色>，<时间>
```

## 模板 3：能力匹配矩阵

```markdown
| 需求编号 | 客户期望 | 我方能力/产品 | 满足度 | 说明 |
| --- | --- | --- | --- | --- |
| R-007 | <RTO ≤ 15min> | <双 AZ> | ✅ 完全满足 | <前提> |
| R-012 | <51TB 不停机迁移> | <DTS+双跑> | ⚠️ 部分满足 | <大表分批> |
```
满足度取值：完全满足 / 部分满足 / 需定制 / 需第三方 / 不满足。

## 模板 4：方案书骨架（14 章）

```markdown
1. 方案概述与理解客户业务
2. 现状分析与核心痛点
3. 总体架构设计
4. 分模块详细设计
5. 数据迁移 / 系统切换方案
6. 性能与容量设计
7. 安全与合规设计
8. 高可用与容灾
9. 可观测性与运维体系
10. 实施路径与分期计划
11. 项目组织与职责分工
12. 交付物与验收标准
13. 风险与应对
14. 商务说明与报价
```
每章产出二级标题 + 每节 3–5 个要点后再展开。

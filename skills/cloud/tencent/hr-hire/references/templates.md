# 输出模板：hr-hire 招聘助手

`<>` 为占位符，产出时替换。评分脚本输入结构见 `scripts/score_candidates.py` 与 `examples/candidates.example.json`。

## 模板 1：岗位 JD

```markdown
# <岗位名称（职级）>

**岗位亮点**：<2 句，做什么、为什么值得来>

## 核心职责
- <动词开头，写清产出物 1>
- <职责 2>
- <职责 3>

## 硬性要求
- <学历/年限/必备技能/证书/语言>

## 加分项
- <与硬性要求分开>

## 薪酬与用工形式
<区间 + 结构 / 正式·外包·驻场·远程 / 地点>

## 面试流程
<轮次、形式、周期>
```

## 模板 2：候选人评分卡

```markdown
### 候选人：<姓名> <来源>

**匹配分：<N> / 100**　建议：<进入面试 / 初筛电话 / 备选 / 不通过>

| 维度 | 权重 | 得分 | 证据（简历原文摘录） |
| --- | --- | --- | --- |
| 硬性门槛 | 30 | <n> | <...> |
| 经验匹配 | 25 | <n> | <...> |
| 技能深度 | 20 | <n> | <...> |
| 项目复杂度 | 15 | <n> | <...> |
| 稳定性 | 10 | <n> | <...> |

**存疑点（面试需核实）**
1. <...>
```

## 模板 3：面试问题

```markdown
**Q：<问题>**
- 考察点：<...>
- 好答案特征：<...>
- 警惕信号：<...>
```

## 模板 4：面后评估表

```markdown
| 维度 | 权重 | 评分（1–5） | 依据 |
| --- | --- | --- | --- |
| 专业能力 | 35% | | |
| 问题解决 | 25% | | |
| 沟通协作 | 20% | | |
| 动机与稳定性 | 10% | | |
| 文化适配 | 10% | | |

**结论**：推荐 / 备选（条件）/ 不通过
**理由**：<2–3 句，指向证据>
```

## 模板 5：拒绝信

```markdown
感谢您投入时间参与 <岗位> 的面试。经过综合评估，本次暂不推进您的 candidacy。
<可选一句具体反馈>。
我们会在人才库保留您的信息，后续有匹配机会会再联系。
```

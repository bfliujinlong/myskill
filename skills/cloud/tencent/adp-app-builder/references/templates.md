# 输出模板：ADP 应用构建专家

`<>` 为占位符，产出时替换。

## 模板 1：应用设计说明

```markdown
# <应用名> 设计说明

- 应用形态：<单 Agent 对话 / 工作流编排 / 多 Agent 协作 / 知识库问答>
- 目标用户：<谁>
- 输入 / 输出：<什么 → 什么>
- 发布渠道：<Web / API / IM>
- 知识来源：<文档集/数据库>
- 动作边界：<能调用什么、不能做什么>
- 失败兜底：<无法回答/工具失败时的行为>
```

## 模板 2：System Prompt（六段式）

```markdown
## 角色
你是<角色>，服务<目标用户>，擅长<能力>。

## 目标
<一次对话要达成什么>

## 边界
- 不做：<...>
- 不回答：<...>，遇到时引导 <兜底动作>

## 输出格式
<结构化模板/JSON schema/字数限制>

## 反例
输入 <...> 时不应该 <...>，应该 <...>

## 兜底
信息不足时：<问什么澄清问题>；工具失败时：<降级行为>
```

# 云迁移交付规范

## 方法论
迁移项目按 **Landing Zone → 评估 → 设计 → 迁移 → 验收** 五阶段推进：

1. **Landing Zone**：8 个领域 —— 身份与权限、网络、资源组织、合规审计、安全、运维监控、成本、自动化。
2. **评估**：资源清单（计算/存储/数据库/中间件/网络）+ 依赖关系 + 兼容性风险。
3. **设计**：HLD（架构选型、双活/多 AZ、网络拓扑）→ LLD（组件参数、迁移批次、回滚方案）。
4. **迁移**：先非生产后生产，先无状态后有状态；每批有明确回滚点。
5. **验收**：性能基线对比、数据一致性校验、业务功能回归。

## 文档层级
| 文档 | 内容 | 规模参考 |
|---|---|---|
| HLD | 架构决策、领域设计、选型理由 | 20–30 页 |
| LLD | 组件参数、配置清单、实施步骤、回滚 | 按模块展开 |
| SOW | 范围、交付物、里程碑、验收标准、报价 | 标准 **14 章** |

## AC-MIG 定价模型
- 标准人天单价：**$350 / 人天**
- 工作量按角色拆分评估：架构师、迁移工程师、DBA、数据工程师、PM
- 报价必须给出**人天 × 角色**的明细表，不能只给一个总数
- 涉及多区域/多可用区、数据库异构迁移时单独计列风险工时

## 数字口径（写报价时必填）
- 资源数量：区分实例规格与数量，标注源端采集时间
- 数据量：区分**全量快照**与**增量**，单位明确 TB/GB
- 停机窗口：可用停机时长（RTO）与数据丢失容忍（RPO）必须确认，未确认不得出终版报价
- 假设条件单列一节，所有未确认项写入"待确认清单"

## 常见风险（必须在方案中显式回应）
- 异构数据库迁移的 DDL/函数不兼容
- 源端数据源未绑定生产环境或字段未映射
- Serverless 资源组缺少自定义依赖包
- 跨地域带宽成本与传输时长

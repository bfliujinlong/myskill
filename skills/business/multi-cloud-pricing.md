# 多云价格对比与推荐 — 售前 Skill

**触发词**：`多云对比` / `云报价` / `选云推荐` / `价格对比`

**用途**：售前阶段，针对客户需求生成多云（AWS / Azure / GCP / 阿里云 / 腾讯云 / 华为云 / OCI / 火山引擎）的价格对比与推荐建议，支持快速出具报价底图。

---

## 1. Skill 输入

每次调用时，需提供以下信息：

```yaml
客户信息:
  - 客户行业: [例如 互联网 / 企业软件 / 游戏 / 教育 / 金融]
  - 客户地域: [例如 仅中国大陆 / 海外 / 中国+海外]
  - 合规要求: [例如 等保2.0 / 数据不出境 / SOC2 / 无特殊要求]

技术需求:
  - 计算: [例如 EC2/虚拟机 规格、数量、使用时长]
  - 储存: [例如 S3/OSS 容量、访问模式]
  - 数据库: [例如 RDS/关系库/无服务/缓存]
  - 网络: [例如 带宽、专线、跨区域、CDN]
  - AI/Agent: [例如 大模型推理/向量检索/Agent架构是否需要]
  - 其他: [特定服务]

报价维度:
  - 主要看重: [价格 / 合规 / 全球覆盖 / 成熟度 / 服务]
  - 报价类型: [月度 / 年度 / 弹性]
```

## 2. Skill 能输出

### 2.1 价格对比表（示例格式）

| 服务类别 | AWS us-east-1 | 阿里云 杭州 | 腾讯云 上海 | 备注 |
|---|---|---|---|---|
| 计算（通用2核4G） | $XX/月 | ¥XX/月 | ¥XX/月 | 按需/包年 |
| 对象存储（1TB） | $XX/月 | ¥XX/月 | ¥XX/月 | 按流量/请求计 |
| RDS（中等规格） | $XX/月 | ¥XX/月 | ¥XX/月 | 含备份 |
| 带宽（公网出流量） | $XX/GB | ¥XX/GB | ¥XX/GB | 区别千兆/百兆 |
| AI推理（如有） | $XX/1K Token | - | - | 本次不展开 |

> 注：价格需根据实际查詢數據補入，此處爲模板。

### 2.2 能力矩陣附注

使用已有的能力矩陣做輔助判斷：

- AWS / Azure / GCP：在海外覆蓋、IaC生態、DR設計、Well-Architected成熟度上佔優
- 阿里雲 / 騰訊雲 / 華為雲：在等保合規、數據本地化、國內互聯帶寬上有天然優勢
- OCI：在某些場景下成本結構有特點，但整體生態/覆蓋少於前列
- 火山引擎：新興雲，快速迭代，部分能力仍有限

### 2.3 推薦結論格式

```
[客户画像]：
- 行业：X
- 地域：Y
- 合规：Z

[推荐云]：
1. 主推：XXX（理由：价格/合规/覆盖/成熟度...）
2. 次选：YYY（理由：...）
3. 备选：ZZZ（理由：...）

[价格敏感型替代逻辑]：
- 若只看价格，国内云在某些计算/存储品类更具优势
- 若需要出海/全球覆盖/成熟DR/IaC生态，海外云更合适
- 若等保/數據不出境是硬要求，優先考慮国内云

[风险提示]：
- 价格会随规格、流量、预付方式变化，仅供底图
- 合规与服务能力不在纯价格对比中，需单独确认
```

## 3. Skill 工作流

### 第一步：收需求
- 輸入客戶技術需求 + 合規 + 重點維度
- 若缺項，標注為「需確認」

### 第二步：查价（根据能力范围）
目前可用的查价能力：
- **AWS**：已集成 `awslabs.aws-pricing-mcp-server`，可查多個服務價格
- **其他雲**：可根據已有知識庫與公開報價體系の经验做對比估算，必要時標注「需云商确认」

### 第三步：生成对比
- 拼出价格对比表
- 加能力矩陣評分作輔助參考
- 按客户画像給出主推/次选/备选

### 第四步：輸出給售前
- 直接可用於進一步和雲商確認
- 也可作為內部快速对齐的底稿

---

## 4. 使用示例

### 示例 A：简单的出海应用报价

輸入：
```
客户：互联网创业公司
地域：主要用户在欧洲，部分在国内
合规：无特殊要求
计算：2台通用虚拟机，每月720小时
存储：2TB对象存储，中等访问
数据库：1个中等RDS
网络：百兆公网出流量
关注：价格 + 海外覆盖
```

輸出（示意）：
```
主推：AWS us-east-1（欧洲用户覆盖好，生态成熟）
次选：GCP（歐洲覆蓋也不錯，價格有時更具競爭力）
备选：阿里云国际(/亚太)节点（特定情景下性价比高）

价格对比：
- 计算：AWS $XX/月 vs GCP $XX/月 vs 阿里云国际 ¥XX/月
- 存储：按用量计，三者結構相似但單價略有不同
- RDS：AWS/Azure/GCP成熟，國内雲在特定規格下價格更具競爭力
```

## 5. 後續擴展

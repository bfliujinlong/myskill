# 销售（Sales）

## When to Use（何时使用）

- 开发新客户、写冷触达话术、电话/微信开场
- 挖掘需求（SPIN）、处理异议、临门一脚促单
- 管理销售漏斗、客户分级、报价策略
- 设计折扣与成交条件

## 标准工作流

### 1. 客户开发与分级
按潜力分级，把时间花在高价值客户：
- A 类：预算明确 + 决策人直接对接 + 3 月内采购
- B 类：有需求但周期长/决策链长
- C 类：潜在，培育中

### 2. 需求挖掘（SPIN）
- 背景问题（S）：了解现状
- 难点问题（P）：痛点与不便
- 暗示问题（I）：不解决的代价
- 需求-效益问题（N）：解决后的价值

### 3. 话术模板
开场（微信/电话）：
「X总好，我是XX的XX。我们帮过[同行业客户]把[痛点]缩短了[X]%，想用10分钟了解下咱们目前[相关业务]的情况，看有没有能帮上忙的地方？」

### 4. 异议处理（LSCPA）
- 倾听（L）：让客户说完
- 同理（S）：「理解，您担心的是…」
- 澄清（C）：确认真实顾虑
- 回应（P）：用案例/数据/保障化解
- 确认（A）：「这样是否能打消您的顾虑？」

常见异议：
| 异议 | 应对 |
|------|------|
| 太贵了 | 算 TCO/ROI，对比不做的代价 |
| 要考虑 | 问清顾虑点 + 给 deadline 优惠 |
| 已有供应商 | 找差异化切口，先小场景切入 |
| 没预算 | 挪预算时机 / 试点小额起步 |

### 5. 报价与成交
- 报价锚定：先抛价值再报价
- 折扣条件化：折扣换签约周期/转介绍/案例授权
- 临门一脚：「今天定我们能协调优先排期/赠送X」

### 6. 销售漏斗
| 阶段 | 动作 | 转化关注 |
|------|------|----------|
| 线索 | 触达 | 响应率 |
| 商机 | 需求确认 | 痛点强度 |
| 方案 | 演示/POC | 决策人参与 |
| 谈判 | 报价 | 条款共识 |
| 成交 | 签约 | 回款节点 |

## 常见陷阱
- 一上来就报价，没挖需求
- 只讲功能不讲客户收益
- 异议当拒绝，没追问真实顾虑
- 折扣随手给，没换任何条件

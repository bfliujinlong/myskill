# HLD 架构设计技能

**触发词**：`HLD` / `架构设计` / `高层设计` / `架构方案` / `技术方案`

**用途**：基于 SmartCare 案例集沉淀的架构设计模式，快速产出规范化的 HLD 方案文档。

---

## 1. HLD 标准结构（八章节）

| 章节 | 内容 | 要点 |
|---|---|---|
| 1. 项目背景 | 客户简介、业务现状、项目目标 | 一句话说清"为什么要做" |
| 2. 当前问题 | 痛点分析、技术债务、业务瓶颈 | 量化问题（成本/效率/风险） |
| 3. 调研评估 | 调研方式、现状梳理、需求分析 | HLD/LLD 调研表、Workshop |
| 4. 架构设计 | 总体架构、模块设计、网络拓扑、安全设计 | 分层 + 分模块 |
| 5. 方案实施 | 实施步骤、割接方案、风险控制 | 分阶段、可回滚 |
| 6. 集成测试 | 功能验证、性能测试、安全测试 | 测试用例 + 验收标准 |
| 7. 培训支持 | 知识转移、SOP、运维赋能 | 文档交付清单 |
| 8. 客户价值 | 量化收益、后续规划 | 降本/增效/合规/安全 |

## 2. 六大架构场景模板

### 2.1 Landing Zone 架构

```
1. 账号设计
   - 多账号体系（核心/成员/共享/日志/审计）
   - 账号开通、域名备案、标签配置

2. 网络设计
   - 生产/测试环境隔离
   - 公网统一出入口
   - VPC/子网划分、NAT网关、中转网关
   - CEN/云联网跨账号互联

3. 身份权限
   - MFA 启用、STS 配置
   - IAM Role 按职能划分（安全管理员/运维/开发）
   - SSO 单点登录对接

4. 安全合规
   - Security Hub / GuardDuty / 配置审计
   - 操作审计、网络流日志统一投递到 S3/OSS
   - 等保/ISO/SOC 合规映射

5. 监控告警
   - CloudWatch/云监控指标采集
   - 告警策略配置（MTTD 目标）
   - 费用标签设置、成本异常告警

6. 成本管理
   - 费用标签、分摊策略
   - 预算告警、成本异常检测
   - 资源共担（NAT/安全组件）
```

### 2.2 云迁移架构

```
1. 调研梳理
   - 业务系统架构、应用部署组件
   - 增量数据来源/存储目录
   - 业务上下游调用关系
   - 数据库现状（数据量/定时Job/用户权限）

2. 方案设计
   - 整体基础框架（网络/安全）
   - 按组件设计迁移方案
   - 割接窗口规划（业务低峰期）
   - 回滚方案

3. 迁移实施
   - 全量+增量同步
   - 数据一致性校验
   - 灰度切换、业务验证

4. 优化交付
   - 性能调优、配置优化
   - 成本对比（源端 vs 目标端）
   - 知识转移、SOP 交付
```

### 2.3 Well-Architected 优化

```
1. 资源治理
   - 资源组隔离（项目/环境/部门）
   - 标签规范化（预制标签策略）
   - 闲置资源自动化治理

2. 身份权限
   - IDaaS 统一账户
   - 基于资源组精细化授权
   - AK 代码明文治理、定期轮换
   - 供应商账号及时回收

3. 安全加固
   - WAF/DDoS/零信任部署
   - KMS 加密、操作审计
   - 漏洞扫描、补丁管理

4. 成本优化
   - 实例规格降配（如 C5→C6）
   - 磁盘类型优化（GP3）
   - 预留实例/节省计划
   - 闲置资源清理
```

### 2.4 大数据迁移架构

```
1. 现状评估
   - 源集群架构、计算/存储/网络资源
   - 数据量、工作负载特征
   - 组件清单（Hive/Spark/Flink/Doris...）

2. 迁移方案
   - 目标侧架构设计（EMR/WeData/DLC）
   - 组件兼容性分析
   - 元数据迁移（Doris→StarRocks）
   - 任务迁移（DataWorks→WeData）

3. 成本评估
   - 迁移前后成本对比
   - 存算分离架构优化
   - Serverless 弹性计算

4. 割接重保
   - 业务低峰期执行
   - 数据校验、任务验证
   - 双跑对比、灰度切换
```

### 2.5 IaC 基础设施即代码

```
1. 架构设计
   - 整体 IaC 架构（Terraform/ROS/CADT）
   - 模块划分（网络/计算/存储/安全）
   - 状态管理、远程后端

2. 模块开发
   - 基础模块开发（VPC/ECS/RDS/Redis）
   - Provider 适配（开源→目标云）
   - 模块注册表/复用体系

3. 流水线
   - GitHub Actions / Azure DevOps
   - Plan/Apply 自动化
   - 变更审批、可追溯

4. 标准化
   - 命名规范、标签策略
   - SOP 文档、变更审批机制
```

### 2.6 容灾 DR 架构

```
1. 目标定义
   - RPO（恢复点目标）
   - RTO（恢复时间目标）

2. 网络设计
   - 生产/灾备地域内网联通
   - 灾备地域外部访问链路
   - DNS 切换策略

3. 数据复制
   - Oracle DataGuard / MySQL 主从
   - 存储级复制（块存储/对象存储）
   - 数据一致性校验

4. 切换演练
   - 灾难恢复流程（DRP）
   - 切换步骤、回切步骤
   - 定期演练、文档更新
```

## 4. 使用示例

**输入**：
```
客户：某跨国制造企业
需求：将分散在 AWS Global、Azure 国际、阿里云的 30 套业务系统
      统一迁移到阿里云，构建 Landing Zone
要求：等保三级、多账号隔离、成本优化
```

**输出**：
按上述八章节结构 + Landing Zone 模板，产出完整 HLD 文档。

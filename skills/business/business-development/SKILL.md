# 商务（Business Development）

## When to Use（何时使用）

- 寻找/评估合作伙伴、渠道、生态绑定
- 商务谈判：价格、账期、排他、份额、违约
- 起草/审阅合同条款要点
- 竞品分析、市场进入策略、商业模式画布

## 标准工作流

### 1. 合作拓展：找对人
- 目标画像：规模、痛点、互补性、决策人
- 价值主张：我们能给对方带来什么（流量/技术/客户/品牌）
- 接触路径：转介绍 > 行业活动 > 冷触达

### 2. 商务谈判框架
谈判前固定底线与弹性：
| 维度 | 底线（不可让） | 弹性（可交换） |
|------|----------------|----------------|
| 价格 | | ✓ |
| 账期 | | ✓ |
| 排他 | | ✓ |
| 数据权属 | ✓ | |

原则：用「非价格条款」换价格；每次让步都要换取对方一个承诺。

### 3. 合同审阅要点
- 主体与授权：对方有无签约资格
- 标的/范围：避免模糊导致无限交付
- 付款：节点、比例、逾期违约金
- 知识产权：归属、许可范围
- 保密与竞业：期限、范围
- 终止：条件、善后、数据返还
- 争议解决：管辖地、仲裁 vs 诉讼

### 5. 商业模式画布（九宫格）
客户细分 / 价值主张 / 渠道 / 客户关系 / 收入来源 / 核心资源 / 关键业务 / 重要合作 / 成本结构

## 常见陷阱
- 只谈价格不谈条款，签完才发现账期 90 天
- 口头承诺不写进合同
- 竞品分析流于功能罗列，没指出「为什么选我」
- 合作只讲自己要什么，不讲对方得到什么

# 报告解读框架 + 急症红线速查

> 本文件供 medical-advisor skill 参考。所有内容非诊断，最终以临床为准。

## 一、急症红线（出现任一→强制引导120/急诊）

| 红旗症状 | 可能指向 |
|---|---|
| 胸痛/胸闷 + 呼吸困难 | 肺栓塞、心梗 |
| 单侧腿肿腿疼 + 喘不上气 | 下肢静脉血栓脱落→肺栓塞（高危组合）|
| 晕厥 / 眼前发黑 / 出冷汗 | 休克前兆、肺栓塞、心律失常 |
| 血氧 < 95%（静息）| 缺氧，需紧急评估 |
| 收缩压 < 90 或骤降 | 休克 |
| 心率 > 120 或 < 40 | 心律失常/休克 |
| 咯血 | 肺栓塞、结核、肿瘤（需排查）|
| 剧烈头痛 + 呕吐 + 颈硬 | 蛛网膜下腔出血（致死率高）|
| 肢体无力/口歪/言语不清 | 卒中（FAST）|

**产后/孕期特别加两条**：
- 产后突发喘憋/腿肿 → 肺栓塞极高危，别等
- 孕晚期头痛眼花 + 血压高 → 子痫前期

## 二、常见报告类型解读要点

### 肺栓塞 CTA（肺动脉造影）
- 分级 1-4（4最重）：看血管堵多少
- 关键不在级别，在**临床指标**（血压/心率/血氧/晕厥）
- 主干堵塞(4级)+血压稳 ≠ 一定最急；2-3级+休克 反而更急

### 血常规
- 白细胞高 → 感染/炎症
- 血红蛋白低 → 贫血
- 血小板低 → 出血风险/药物影响（如肝素诱导）

### 凝血/D-二聚体
- 升高 → 血栓可能（但术后/产后本就高，特异性低）
- 正常 → 基本排除急性血栓

### 影像（CT/MRI/超声）
- 看"部位 + 大小 + 性质（实性/囊/积液）"
- 标注测量数值（cm/mm），对比既往

### 心电图
- ST 段抬高 → 心梗红旗
- 房颤 → 血栓/卒中风险

## 三、用药整理（不处方，只整理）
用户给处方/药单时：
- 列：药名 / 剂量 / 频次 / 用途（用户说或说明书查）
- 标：禁忌（如哺乳期禁用）、相互作用
- 提醒：调量/停药必须问开药医生

## 附录 E 腾讯云专有口径

**E.1 目标端平台基线**（专有服务名按官方写法，不臆造 / 不翻译）

| 领域 | 腾讯云 基线 |
|---|---|
| 账号与组织架构 | 组织 Organizations 多账号结构（集团账号 / 成员账号）；标签分账与成本归集；共享服务账号承载日志与网络 |
| 网络架构 | VPC + 子网按环境隔离；云联网 CCN 做多地域互联；专线接入 / Direct Connect / VPN 网关做混合云；CLB 承载入口流量；NAT 网关统一出网；对等连接做 VPC 互通 |
| 安全与合规 | 云防火墙 / Web 应用防火墙 WAF / 主机安全 CWP / KMS / DDoS 防护；云审计 CloudAudit 留痕；等保 2.0 三级基线由乙方提供配置项，测评结论归甲方 |
| 身份与访问（IAM） | CAM 用户 / 角色 / 策略；子账号与协作者；STS 临时凭证；消息接收人配置 |
| 计算 | CVM 实例族（标准型 S5 / SA3，按压测调整）；弹性伸缩 AS；TKE 容器服务承载容器化负载 |
| 存储 | COS 存储桶（标准 / 低频 / 归档）；CFS 文件存储；CBS 云硬盘（SSD / 增强型 SSD）；跨地域复制与生命周期 |
| 数据库 | TencentDB MySQL / PostgreSQL；TDSQL 分布式；云数据库 Redis；DTS 数据传输服务做同步与校验 |
| 监控与运维 | 云监控 CM + 日志服务 CLS + 应用性能观测 APM；告警策略与接收组；备份与恢复演练 |

**E.2 迁移工具与方式**
- 主机迁移：在线迁移工具 / 离线镜像导入（按源端形态选型）
- 数据库迁移：DTS 数据传输服务（结构 + 全量 + 增量 + 一致性校验）
- 对象存储迁移：COS 迁移工具 / MSCP
- IaC / 编排：Terraform（腾讯云 Provider）或 TIC 资源编排

**E.3 验收口径**
- 账号体系与权限基线符合《腾讯云 Landing Zone 基线》双方确认版
- 专有名词不翻译：CVM / COS / CCN / CAM / CLB / TKE / CLS
- 等保合规：乙方提供配置基线及整改建议，不承担测评结论

**E.4 商务口径**
- 云资源费用由甲方与腾讯云侧结算，不含在本服务金额内
- 服务包模式：人天 / 人月仅作能力与工作量评估依据，不作为结算依据

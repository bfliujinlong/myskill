## 附录 E 阿里云专有口径

**E.1 目标端平台基线**（专有服务名按官方写法，不臆造 / 不翻译）

| 领域 | 阿里云 基线 |
|---|---|
| 账号与组织架构 | 资源目录 / 资源管理 多账号结构（管理账号 + 成员账号）；资源组与标签分账；共享服务账号承载日志审计与网络；Landing Zone 基线以双方确认版为准 |
| 网络架构 | VPC + 交换机（VSwitch）按环境/分层划分；云企业网 CEN 做多地域互联；高速通道 / VPN 网关做混合云接入；SLB / ALB 承载入口流量；NAT 网关统一出网 |
| 安全与合规 | 云防火墙 / WAF / 云安全中心（安骑士）/ KMS / DDoS 高防；操作审计 ActionTrail + 配置审计做合规留痕；等保 2.0 三级基线由乙方提供配置项，测评结论归甲方 |
| 身份与访问（IAM） | RAM 用户 / 角色 / 策略；STS 临时凭证；跨账号 RAM 角色授权；权限边界与最小权限矩阵 |
| 计算 | ECS 实例规格族（通用型 g7 / 计算型 c7 / 内存型 r7）；弹性伸缩 ESS；ACK 承载容器化负载 |
| 存储 | OSS（标准 / 低频 / 归档）；NAS 共享文件存储；ESSD 块存储；跨区域复制与生命周期策略 |
| 数据库 | RDS MySQL / PostgreSQL；PolarDB 集群版；ADB 分析型；Redis / Tair 缓存；DTS 做同步与一致性校验 |
| 监控与运维 | 云监控 + SLS 日志服务 + ARMS 应用监控；告警联系人与行动策略；备份策略与恢复演练 |

**E.2 迁移工具与方式**
- 主机迁移：SMC（服务器迁移中心），源端安装 SMC 客户端后做镜像/增量同步
- 数据库迁移：DTS（结构迁移 + 全量 + 增量 + 校验）
- 数据/大数据迁移：DataWorks / MaxCompute 侧目标端架构责任方需在责任矩阵中写明
- IaC / 编排：ROS（资源编排）或 Terraform（阿里云 Provider）

**E.3 验收口径**
- 账号体系与权限基线符合《阿里云 Landing Zone 基线》双方确认版
- 专有名词不翻译：ECS / OSS / VPC / CEN / RAM / DTS / SMC / SLS
- 等保合规：乙方提供配置基线及整改建议，不承担测评结论

**E.4 商务口径**
- 云资源费用（包年包月 / 按量 / PHA）由甲方与阿里云侧结算，不含在本服务金额内
- 服务包模式：人天 / 人月仅作能力与工作量评估依据，不作为结算、签到、出勤验收依据

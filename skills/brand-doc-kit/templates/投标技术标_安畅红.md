## 附录 E 安畅（中立 MSP 口径）专有口径

**E.1 目标端平台基线**（专有服务名按官方写法，不臆造 / 不翻译）

| 领域 | 安畅（中立 MSP 口径） 基线 |
|---|---|
| 账号与组织架构 | 按目标云约定建立账号 / 订阅体系；管理账号与业务账号分离；标签与分账规则先行；根账号由甲方持有 |
| 网络架构 | 地址规划与网段分配表；跨地域互联方案依目标云选型；专线 / VPN 双链路冗余；出网与 NAT 集中管控 |
| 安全与合规 | 边界防护 / WAF / 主机安全 / 密钥管理；安全基线与加固清单；等保与合规整改建议（不承担测评结论） |
| 身份与访问（IAM） | 最小权限角色矩阵；人机分离（运维账号 / 程序账号）；临时凭证；季度权限复核 |
| 计算 | 实例族选型与容量规划；伸缩组与弹性策略；容器平台依目标云选型；黄金镜像管理 |
| 存储 | 对象 / 文件 / 块存储分层；生命周期与跨区域复制；静态加密与密钥托管 |
| 数据库 | 引擎与版本选型；高可用架构（主备 / 集群）；迁移工具与一致性校验；缓存层设计 |
| 监控与运维 | 指标 / 日志 / 链路三类采集；告警分级与值班机制；备份与恢复演练；移交运维手册 |

**E.2 迁移工具与方式**
- 主机迁移：按源端与目标云选型，优先目标云官方迁移服务
- 数据库迁移：官方数据传输服务 + 停机窗口内增量追平 + Count/MD5 校验
- 割接：分批分波次，每套系统单独验证与回退预案
- IaC / 编排：Terraform（云中立写法，按目标云切换 Provider）

**E.3 验收口径**
- 以《迁移系统范围清单（调研确认版）》为唯一范围基线，各章节数字必须一致
- 每套系统须：迁移验证 + 数据完整性确认 + 功能验证通过 + 双方确认割接完成
- 交付物经甲方书面 / 在线确认即视为该阶段验收通过

**E.4 商务口径**
- 云资源费用由甲方向云厂商直接结算，不含在本服务金额内
- 第三方 License 由甲方承担；范围外工作走 PCR 变更

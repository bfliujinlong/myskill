# 迁移资源评估 · 常见风险清单

> 供 `mig-resource-assessment` 第 6 步「风险初判」逐项比对。
> 命中项写入评估报告的「风险初判」段，标注命中依据与影响面。

## 使用方式

按表逐项比对采集结果，命中则记录：命中条件 + 涉及资源数量 + 对迁移方案的影响（停机窗口 / 工具选型 / 成本）。

## 风险项

| # | 风险类型 | 命中条件 | 影响 | 处置方向 |
|---|---|---|---|---|
| R1 | 异构数据库 | 源库引擎在目标云无托管对等品（如 SQL Server 高版本、Oracle 特定版本） | 工具链不可用，需改造或自建 | 标 Repurchase/Refactor，升级人工评估 |
| R2 | 跨地域带宽 | 源与目标跨地域且数据量 > 10 TB | 传输时间不可控，割接窗口风险 | 评估专线/离线迁移（闪电立方等） |
| R3 | Serverless 依赖 | 存在 Lambda/函数计算/事件驱动链路 | 无法整体平移，需重构触发关系 | 6R 判 Refactor，单列工作量 |
| R4 | 快照增量规模 | 日增数据量 > 全量 5% | 增量同步追不上，割接无法收敛 | 评估 CDC 方案与割接窗口 |
| R5 | 老旧操作系统 | OS 已 EOL（如 CentOS 6、Windows Server 2008） | 目标云无镜像，安全合规不通过 | 标 Refactor/Repurchase，先升 OS |
| R6 | 内网硬编码 IP | 配置中出现内网 IP 直连 | 迁移后网络变更导致服务失联 | 迁移前必须改造为域名/服务发现 |
| R7 |  licence 绑定 | 商业软件 licence 绑定主机特征（MAC/CPU） | 迁移后 licence 失效 | 提前与厂商确认迁移授权 |
| R8 | 共享存储/NAS | 多实例挂载同一共享存储 | 目标侧需对等 NAS，否则读写冲突 | 目标云 NAS 选型前置确认 |
| R9 | 超大单盘 | 单盘 > 16 TB | 目标云单盘上限可能不足 | 提前确认目标上限，必要时拆分 |
| R10 | 公网 IP 依赖 | 业务依赖固定公网 IP（白名单/备案） | 目标侧公网 IP 不可携带 | 评估 EIP 保留或 DNS 切换方案 |

## 判定口径

- 命中 R1/R5/R7 → 影响 6R 策略，必须在评估报告中升级提示
- 命中 R2/R4 → 影响割接窗口，写入报告的「时间约束」段
- 其余 → 记录进报告风险清单，作为后续 SOW 假设前提的输入

## 维护

新增风险项须附「命中条件」的可判定表达式，不可只写风险名称。

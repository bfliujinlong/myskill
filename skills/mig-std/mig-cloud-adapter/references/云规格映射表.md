## 计算

| AWS | 阿里云 | 华为云 | 备注 |
|---|---|---|---|
| t3.medium (2C4G) | ecs.t6-c1m2.large | s6.medium.2 | 突发型，注意 CPU 积分 |
| m5.large (2C8G) | ecs.g6.large | s6.large.2 | 通用型 |
| m5.xlarge (4C16G) | ecs.g6.xlarge | s6.xlarge.4 | 通用型 |
| c5.xlarge (4C8G) | ecs.c6.xlarge | c6.xlarge.2 | 计算型 |

## 数据库

| AWS | 阿里云 | 备注 |
|---|---|---|
| RDS MySQL 5.7 | RDS MySQL 5.7 | 同构，直接迁移 |
| RDS MySQL 8.0 | RDS MySQL 8.0 | 同构 |
| Aurora MySQL | PolarDB MySQL | 需评估兼容性 |
| RDS PostgreSQL | RDS PostgreSQL | 同构 |
| Oracle | PolarDB-O / RDS Oracle | 异构，复杂度高 |

## 存储

| AWS | 阿里云 | 备注 |
|---|---|---|
| EBS gp3 | ESSD PL1 | IOPS 需对标 |
| S3 Standard | OSS 标准存储 | 语义基本一致 |
| S3 Glacier | OSS 归档存储 | 取回策略不同 |

## 使用约束

- 本表用于**规模评估**阶段的量级换算，不是最终选型
- 实际选型以目标云官方规格文档 + 性能测试为准
- 异构项（Oracle / Aurora）单独标记，进复杂度系数

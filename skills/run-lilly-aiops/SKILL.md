## Gotchas

- **`cd /home/ubuntu` 是硬要求。** `pptxgenjs` 装在 `/home/ubuntu/node_modules`，全局没有。
  从 `/tmp` 或其它目录跑会得到 `MODULE_NOT_FOUND`。这不是脚本 bug，别去改 require 路径。
- **`clone_aiops_quotation.py` 的 SRC 是死的**（历史遗留，勿直接跑）：
  它硬编码 `.../doc_79b759de56de_中东迪拜客户_云迁移与运维报价单_中文版_V2.xlsx`，该文件已不存在，
  且真实模板**没有 `_V2` 后缀**。直接跑必然 `FileNotFoundError`。
  本 skill 的 driver 已改用真实路径 `/data/cloud-docs/客户报价单/中东迪拜客户_云迁移与运维报价单_中文版.xlsx`（58,964 B）。
- **PPT 配色不是阿里橙。** 实测色值：`1E293B`(28) `1E2761`(24) `0D9488`(17) `FFFFFF`(14) `64748B`(13)
  `000000`(12) `CADCFC`(12) `F8FAFC`(11)。`FF6A00` 出现 **0 次**。
  阿里橙 `FF6A00` 只落在 `/data/cloud-docs/AIOPS售前/AIOPS_报价单_阿里橙.docx` 那条 docx 报价线上，
  PPT 线从未采用。若客户要求阿里橙标准，需要改 `scripts/create_lilly_ppt.js:9-15` 的常量，不是改产物。
- **曾出现 353s 未返回**：非脚本问题，是当时网络/环境假死。实测干净执行 0.05s。超过 10s 就应怀疑环境而非脚本。
- 交付物**不得虚构人员/案例/证书**，SOW 与报价单一律以 `Lilly_AIOps/src/sow.txt` 为准。

## Troubleshooting

| 症状 | 原因 | 处理 |
|---|---|---|
| `Cannot find module 'pptxgenjs'` | 不在 `/home/ubuntu` 下执行 | `cd /home/ubuntu` 后重跑 |
| `FileNotFoundError: ..._V2.xlsx` | 直接调用了旧 `clone_aiops_quotation.py` | 走 driver，或用本 skill 的真实 SRC |
| 产物页数 != 8 | 脚本被改动 | `git diff scripts/create_lilly_ppt.js` 复核 |
| 要求阿里橙但产物无橙 | PPT 线本就没用阿里橙 | 改脚本头部颜色常量后重跑 |
